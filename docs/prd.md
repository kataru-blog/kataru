
# 블로그 서비스 PRD (Product Requirements Document)

## 1. 개요
본 문서는 블로그 서비스의 요구사항을 정의하며, LLM 기반 분석 및 기능 개발에 활용할 수 있도록 상세한 기술 정보를 제공합니다.  
해당 서비스는 **커스텀 도메인 지원**, **마크다운 기반 게시글 작성**, **태그 기반 카테고리 시스템**, **댓글 및 추천/조회수 카운트 기능**을 지원합니다.

---

## 2. 서비스 목표
- 사용자에게 **커스텀 도메인**을 통한 브랜드화 지원.
- **마크다운 기반 작성 환경**을 제공해 개발자 친화적인 블로그 작성 경험 강화.
- **태그 중심의 카테고리 구조**를 통해 유연한 콘텐츠 분류 및 검색 최적화.
- 조회수 및 추천수를 기반으로 콘텐츠 인기 지표 제공.
- 향후 대댓글 및 다중 도메인 지원 확장성 확보.

---

## 3. 주요 기능

### 3.1 커스텀 도메인 기능
- **설명**: 하나의 블로그에 여러 개의 커스텀 도메인을 연결 가능.
- **예시**
  - 기본 URL: `kataru.dev/{userEmail}/post/{postNumber}`
  - 커스텀 URL: `customdomain.com/post/{postNumber}`
- **요구사항**
  - 블로그별 다중 도메인 매핑 지원.
  - SSL 인증서 자동 적용 및 HTTPS 지원.
  - 기본 도메인 및 커스텀 도메인 간 리다이렉션 지원.

---

### 3.2 게시글 관리
- **설명**: 마크다운 기반으로 작성, 태그로 분류.
- **주요 기능**
  - 게시글 작성 / 수정 / 삭제
  - 마크다운 렌더링 및 실시간 미리보기
  - 태그 기반 분류 및 검색 기능
- **데이터 요구사항**
  - 게시글은 `블로그ID`, `제목`, `내용(Markdown)`, `태그`, `조회수`, `추천수`, `댓글 가능 여부`, `공지 여부`, `생성일`, `수정일` 포함.

---

### 3.3 태그 시스템
- **설명**: 카테고리 대신 태그를 사용하여 콘텐츠 분류.
- **관계**: 게시글과 태그는 **N:N 관계**
- **주요 기능**
  - 태그 생성 / 삭제 / 관리
  - 태그별 게시글 목록 필터링 지원

---

### 3.4 댓글 시스템
- **설명**: 게시글별 댓글 작성 및 관리 지원.
- **주요 기능**
  - 댓글 CRUD
  - 비밀 댓글 설정 가능
  - 대댓글(parentId) 구조 설계, 향후 지원 예정
- **데이터 요구사항**
  - `사용자ID`, `블로그ID`, `내용`, `비밀댓글 여부`, `parentId`, `생성일`, `수정일`

---

### 3.5 조회수 & 추천수 관리
- **조회수 테이블**
  - 사용자가 게시글을 읽을 때마다 카운트
  - 고유 사용자 세션 기반 중복 방지
- **추천수 테이블**
  - 사용자가 게시글을 추천할 때 카운트
  - 사용자ID 기준 중복 추천 방지

---

### 3.6 블로그 정보 관리
- **설명**: 블로그 단위의 메타데이터 관리.
- **데이터 요구사항**
  - `블로그 타이틀`
  - `커스텀 도메인 리스트`
  - `설명`
  - `favicon.ico URL`
  - `생성일`
  - `수정일`
- **관계**: 블로그와 유저는 **1:1 관계**

---

## 4. 데이터베이스 모델링

### 4.1 ERD 개요
```
User (1) ─── (1) Blog ─── (N) Post ─── (N) Tag
                      │
                      ├── (N) CustomDomain
                      ├── (N) Comment
                      ├── (N) ViewCount
                      └── (N) LikeCount
```

---

### 4.2 주요 테이블 설계

#### **users**
| 필드명       | 타입        | 설명          |
|-------------|------------|---------------|
| id         | PK         | 사용자 ID      |
| email      | String     | 사용자 이메일   |
| password   | String     | 비밀번호 해시값 |
| created_at | DateTime   | 생성일         |
| updated_at | DateTime   | 수정일         |

#### **blogs**
| 필드명         | 타입      | 설명               |
|---------------|----------|--------------------|
| id           | PK       | 블로그 ID          |
| user_id      | FK       | 사용자 ID          |
| title        | String   | 블로그 타이틀      |
| description  | String   | 블로그 설명        |
| favicon_url  | String   | 파비콘 URL         |
| created_at   | DateTime | 블로그 생성일      |
| updated_at   | DateTime | 블로그 수정일      |

#### **custom_domains**
| 필드명       | 타입      | 설명               |
|-------------|----------|--------------------|
| id         | PK       | 도메인 ID          |
| blog_id    | FK       | 블로그 ID          |
| domain     | String   | 사용자 커스텀 도메인 |
| created_at | DateTime | 생성일             |

#### **posts**
| 필드명         | 타입      | 설명               |
|---------------|----------|--------------------|
| id           | PK       | 게시글 ID          |
| blog_id      | FK       | 블로그 ID          |
| post_number  | Integer  | 블로그별 순차 번호  |
| title        | String   | 게시글 제목        |
| content      | Text     | 마크다운 콘텐츠    |
| thumbnail_url| String   | 섬네일 URL         |
| summary      | String   | 요약               |
| is_notice    | Boolean  | 공지 여부          |
| allow_comment | Boolean | 댓글 허용 여부     |
| created_at   | DateTime | 생성일            |
| updated_at   | DateTime | 수정일            |

#### **tags**
| 필드명       | 타입    | 설명        |
|-------------|--------|------------|
| id         | PK     | 태그 ID     |
| name       | String | 태그명      |

#### **post_tags (N:N 관계)**
| 필드명   | 타입 | 설명     |
|---------|------|---------|
| post_id | FK   | 게시글 ID |
| tag_id  | FK   | 태그 ID   |

#### **comments**
| 필드명       | 타입      | 설명                |
|-------------|----------|---------------------|
| id         | PK       | 댓글 ID             |
| post_id    | FK       | 게시글 ID           |
| user_id    | FK       | 사용자 ID           |
| content    | Text     | 댓글 내용           |
| is_secret  | Boolean  | 비밀 댓글 여부      |
| parent_id  | FK       | 부모 댓글 ID (대댓글) |
| created_at | DateTime | 생성일             |
| updated_at | DateTime | 수정일             |

#### **views**
| 필드명      | 타입    | 설명            |
|------------|--------|-----------------|
| id        | PK     | 조회수 ID        |
| post_id   | FK     | 게시글 ID        |
| count     | Int    | 조회수 카운트     |

#### **likes**
| 필드명      | 타입    | 설명            |
|------------|--------|-----------------|
| id        | PK     | 추천수 ID        |
| post_id   | FK     | 게시글 ID        |
| user_id   | FK     | 사용자 ID        |

#### **images**
| 필드명         | 타입      | 설명                   |
|---------------|----------|------------------------|
| id           | PK       | 이미지 ID              |
| post_id      | FK       | 게시글 ID              |
| original_url | String   | 원본 이미지 URL         |
| thumbnail_url| String   | 섬네일 이미지 URL       |
| r2_key       | String   | R2 스토리지 키          |
| width        | Integer  | 이미지 너비            |
| height       | Integer  | 이미지 높이            |
| size         | Integer  | 파일 크기              |
| mime_type    | String   | MIME 타입              |
| created_at   | DateTime | 생성일                |

---

## 5. 향후 고려사항
- 대댓글 시스템 완전 지원
- 블로그별 통계 페이지 제공 (조회수, 추천수, 태그 인기 순위)
- SEO 최적화: 커스텀 도메인별 메타태그 자동 생성
- 태그 기반 추천 알고리즘 추가

---

## 6. 비기능 요구사항
- **성능**: 게시글 조회 시 SSR 지원 및 캐싱 전략 필요.
- **보안**: 커스텀 도메인 SSL 자동 적용 및 OAuth 로그인 지원.
- **확장성**: 다중 블로그 및 다중 도메인 구조를 고려한 설계.
